# Phase 0 — Orientation

What a server process is, stateless HTTP, where state lives, and the full
lifecycle of one request. Full module descriptions and gates: `CURRICULUM.md`.

**Gate out of this phase:** trace a request end to end and name every layer,
then survive three "what breaks if this layer dies?" follow-ups.

## Layout

- `exercises/` — tutor-written, numbered. Start at `00-smoke-test.md`.
- `notes/` — yours. Written answers, the request-lifecycle diagram, anything
  worth keeping. Committed at session end.

No code is graded in this phase; written answers are the artifact.
