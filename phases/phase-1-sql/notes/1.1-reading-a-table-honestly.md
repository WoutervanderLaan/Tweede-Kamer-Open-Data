# Notes

Adding a description to a column:
`COMMENT ON COLUMN subscriptions.ended_on IS 'NULL = still running';`

> A comment documents a rule; it doesn't enforce it.
> A comment is a promise, not a guarantee

output:

| Column     | Type   | Collation | Nullable | Default                      | Storage  | Compression | Stats target | Description          |
| ---------- | ------ | --------- | -------- | ---------------------------- | -------- | ----------- | ------------ | -------------------- |
| id         | bigint |           | not null | generated always as identity | plain    |             |              |                      |
| user_id    | bigint |           | not null |                              | plain    |             |              |                      |
| plan       | text   |           | not null |                              | extended |             |              |                      |
| started_on | date   |           | not null |                              | plain    |             |              |                      |
| ended_on   | date   |           |          |                              | plain    |             |              | NULL = still running |
